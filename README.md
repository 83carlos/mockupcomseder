# COMSEDER

Site institucional responsivo da COMSEDER, implementado em React e Vite a partir dos layouts oficiais fornecidos em PDF.

## Desenvolvimento local

```bash
npm install
npm run dev
```

## Produção

```bash
npm run build
```

O workflow `deploy-pages.yml` gera automaticamente a versão hospedada no GitHub Pages a cada atualização da branch `main`.
